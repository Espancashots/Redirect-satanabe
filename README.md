# Satanabe Store — Página de links oficiais

Site responsivo de página única, com tema preto e vermelho, incluindo links para WhatsApp, TikTok, Instagram, YouTube e Discord.

## Publicação grátis

Os arquivos `index.html`, `favicon.svg`, `site.webmanifest` e `robots.txt` devem ficar na raiz do seu site. Não precisa instalar nada nem ter banco de dados.

### GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie esses arquivos para a raiz do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.
4. O GitHub fornece um link público terminado em `github.io`.

### Vercel
Crie um projeto na Vercel e envie os arquivos, ou conecte o repositório. A Vercel fornece um domínio `.vercel.app` no plano gratuito para uso pessoal, sujeito aos termos do serviço.

## Personalização
- Texto e links: altere diretamente o arquivo `index.html`.
- Estilos: as cores ficam dentro da tag `<style>` no `index.html`.
- Ícone do navegador: `favicon.svg`.

Os links fornecidos foram preservados. Para Discord, confira regularmente se o convite permanece válido.
